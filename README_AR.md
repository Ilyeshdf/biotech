# تطبيق طبي - Flutter

تطبيق طبي شامل مبني بـ Flutter مع واجهة مستخدم حديثة وهيكل تطبيق كامل. يعرض هذا التطبيق منصة طبية متكاملة مع بيانات وهمية للاختبار والتطوير.

## 🚀 الميزات

### ✅ الميزات المكتملة
- **مصادقة المستخدم** - تسجيل دخول وإنشاء حساب مع بيانات وهمية
- **تصميم واجهة حديث** - واجهة جميلة ومتجاوبة مع المظاهر المظلمة والفاتحة
- **إدارة المواعيد** - عرض وإنشاء وإدارة المواعيد الطبية
- **تتبع الوصفات** - عرض تاريخ الوصفات والتفاصيل
- **نتائج المختبر** - عرض نتائج الفحوصات الطبية
- **البحث عن الصيدليات** - العثور على الصيدليات القريبة مع التفاصيل
- **ملفات الأطباء** - تصفح وعرض معلومات الأطباء
- **تكامل Firebase** - جاهز لتكامل الخلفية
- **إدارة الحالة** - نمط Provider لإدارة حالة التطبيق
- **معالجة الأخطاء** - حدود أخطاء شاملة ومعالجة
- **خدمة البيانات الوهمية** - بيانات اختبار واقعية لجميع الميزات
- **دعم اللغة العربية** - ترجمة كاملة مع تخطيط RTL

### 🔄 قيد التطوير
- الإشعارات الفورية
- المراسلة الفورية
- استشارات الفيديو
- تكامل الدفع

## 📱 هيكل التطبيق

```
lib/
├── constants/          # ثوابت التطبيق والإعدادات
├── models/            # نماذج البيانات (المستخدم، المواعيد، إلخ)
├── providers/         # إدارة الحالة مع Provider
├── screens/           # شاشات واجهة المستخدم
├── services/          # API ومنطق الأعمال
├── theme/             # تنسيق التطبيق والتنسيق
├── utils/             # وظائف مساعدة
├── widgets/           # مكونات واجهة قابلة لإعادة الاستخدام
└── main.dart          # نقطة دخول التطبيق
```

### الميزات المدعومة:

2. اختر **اللغة**
3. اختر **العربية** أو **English**
4. اضغط **تطبيق التغييرات**

## 🔧 الإعداد

### إعداد Firebase
التطبيق مُعد مع Firebase. لاستخدام مشروع Firebase الخاص بك:

1. أنشئ مشروع Firebase
2. حمل `google-services.json` (Android) و `GoogleService-Info.plist` (iOS)
3. ضعهما في المجلدات المناسبة
4. حدث إعدادات Firebase في `firebase_options.dart`

### إعداد API
حالياً يستخدم بيانات وهمية. للاتصال بخلفية حقيقية:

1. حدث `AppConstants.baseUrl` في `lib/constants/app_constants.dart`
2. عدل طرق `ApiService` لإجراء استدعاءات API حقيقية
3. أزل تكامل خدمة البيانات الوهمية
